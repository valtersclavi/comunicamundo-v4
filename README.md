# ComunicAmundo V4

This project follows a disciplined editorial flow: the brief defines the direction, the acquired sources sustain the project, and source expansion happens only when the user explicitly requests it.

- No automatic model suggestions are created during the initial Editorial Project.
- No speculative find-for-me flow is used to invent research paths.
- Source enrichment remains an explicit, user-directed action.
- The PE stays frozen unless the user asks for a revision or expansion.

This repository is aligned with the Hefesto editorial contract and keeps the search and enrichment loops on-demand only.

This is a code repository for the ComunicAmundo V4 platform.
