# Editorial Project freeze before production — 2026-08-29

Canonical decisions frozen at the second human gate:

- The first Editorial Project may present enrichment opportunities once.
- Any later Editorial Project revision must not present enrichment opportunities again.
- There is no exception that resurfaces that section on later revisions.
- Dicas do Hefesto are optional model-knowledge scope. Selecting a Dica is an explicit request to add scope and therefore increases duration.
- The normal Dica flow never offers or infers keeping the previous duration.
- Only an explicit user request to keep duration may open a separate trade-off flow; the user chooses which existing topic loses space.
- A revised Project returns to human approval.
- Production is authorized only by the approved Narrative Axis plus the approved Editorial Project core scope.
- Dicas do Hefesto and enrichment opportunities are decision-support metadata, not production commitments; they must not be passed to architecture, writing, criticism, or editing unless they have first been incorporated into the core Editorial Project and approved.
